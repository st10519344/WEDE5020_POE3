1. Define SEO and explain its purpose in web development.
Search Engine Optimisation (SEO) is the practice of optimising a website to increase its visibility and organic ranking on search engine result pages. Its primary purpose in web development is to make sure that search engines can easily crawl, index, and understand a site's structure so that target users can organically discover the web application.
2. Explain how SEO practices can improve user experience (UX) and website performance.
SEO-driven practices—such as optimizing image sizes, making sure mobile-first responsive layouts, and maintaining clean semantic HTML structures—significantly decrease page load times. This seamless navigation and fast performance directly enhance overall user retention and satisfaction.
3. Discuss the benefits of implementing SEO on a website.
Implementing SEO drives targeted organic traffic, increases brand credibility, and maximizes accessibility for users. For a boutique platform like Aura Living Furniture, it ensures potential customers searching for sustainable timber decor can easily find the storefront without relying solely on paid advertisements.
4. Explain and demonstrate specific SEO techniques using HTML, CSS and JavaScript where applicable.
Technical and on-page SEO techniques include configuring XML sitemaps (⁠sitemap.xml⁠) and crawler instruction files (⁠robots.txt⁠) in the root directory. In HTML, using descriptive page titles, proper heading hierarchies (⁠<h1>⁠ to ⁠<h3>⁠), and descriptive image ⁠alt⁠ attributes ensures search engines correctly parse content.
5. Explain the purpose of HTML meta elements and demonstrate relevant examples.
HTML meta elements reside within the ⁠<head>⁠ tag to provide structured metadata to browsers and search engine crawlers. For example, ⁠<meta name="viewport" content="width=device-width,  makes sure that there is optimal mobile rendering, while description tags summarize page content for search previews.
